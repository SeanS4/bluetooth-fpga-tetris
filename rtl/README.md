# RTL Directory

<p align="center">
  Navigate the SystemVerilog source and build files by design area.
</p>

<div align="center">

| Directory | Contents |
| --- | --- |
| `bitstream/` | Generated FPGA bitstream file used in demo |
| `constraints/` | FPGA pin assignments and timing constraints |
| `game_logic/` | Tetris control, collision, rotation, locking, row-clearing, and piece-selection logic |
| `input/` | GPIO synchronization, pulse generation, and reset handling |
| `ip/` | Vivado IP configuration files for BRAM, clock generation, and HDMI output |
| `rendering/` | VGA timing, color mapping, and rendering logic |
| `testbenches/` | Testbenches used for module verification |
| `top/` | Top-level module logic |

</div>
